# Roadmap

## Phase 1 – Lola-Vertical-Slice

- [x] gemeinsame Inselwelt, Pool und Yacht-Dock
- [x] sechs Lola-Reaktionen und Fahrzeug
- [x] drei datengetriebene Missionen
- [x] Save-/Reload- und Progressionstests
- [x] GitHub Pages

## Phase 1.1 – World-first UX

- [x] Smartphone als echtes Ingame-Overlay
- [x] spielbares Nachrichten-Onboarding
- [x] beantwortbare Chats mit Konsequenzen
- [x] pausierende, missionsbezogene Fahrtereignisse
- [x] verständliche Routen-Trade-offs
- [x] Heat-Stufen, Beziehungstiers und Ergebnisursachen
- [x] reaktive Folgezeilen und Runner-Stile

## Phase 1.2 – Sichtbare Economy

- [x] Strandhütte als eigener Ort auf der Insel
- [x] Ausbaupfad Bungalow, Poolhaus und Villa
- [x] Missions-, Fan- und Cash-Voraussetzungen
- [x] kleine Eindrucksboni ohne kaufbares Vertrauen
- [x] kurze Lola-Einweihungsszene
- [x] Onboarding, Save-Migration und E2E-Test

## Phase 2 – Social Island

- [x] Mia als eigener Kontakt und erster vollständiger Auftrag
- [ ] zwei weitere Mia-Missionen
- [x] erste datengetriebene Bungalow-Zwischenszene
- [ ] fünf weitere kurze Zwischenszenen
- [x] konkretes soziales Gedächtnis für Versprechen und Geheimnisse
- [x] Lola–Mia-Freundschaft und Spannung als persistente Werte
- [ ] Poolhaus als Ort für private Einladungen
- [ ] Nachtabschluss mit sichtbaren Folgen

## Phase 2.05 – Erkundbare Insel

- [x] sieben klickbare Insel-Landmarks inklusive Runner-Home
- [x] wiederverwendbare lokale Ansichten für alle Hauptorte
- [x] einmalige Ortsaktionen mit sichtbaren Kosten und Folgen
- [x] ortsübergreifende Hinweis-Ketten
- [x] Runner-Home als Social Hub mit Erinnerungspinnwand
- [x] dreistufiger Midnight Wing als geheimer Gäste- und Beziehungsspace
- [x] Save-Migration, Unit- und Mobile-E2E-Tests

## Phase 2.1 – Soziales Dreieck

- [ ] Kylie mit drei Missionen und Club-Zugang
- [ ] Terminkonflikte statt beliebiger Fahrtentscheidungen
- [ ] faire Eifersucht nur bei bekannter Ursache
- [ ] Gruppenszenen am Pool, im Club und später in der Villa
- [ ] Jessica und Island Manager als weitere soziale Rollen

Neue Figuren, Locations oder Systeme werden nur ergänzt, wenn sie einen klaren Platz im Kernloop besitzen.
